# 改善ロードマップ

本番レビュー（2026-05）と [`todo.md`](../todo.md) を **2026-06 に一本化**。以降の更新は **本ファイルのみ**。

**凡例:** `[x]` 完了 · `[~]` 一部対応 · `[ ]` 未着手

| レベル | 意味 | いつやるか |
|--------|------|------------|
| **L1** | 最優先 | 残タスク・実機確認など、今の品質の穴 |
| **L2** | 高優先 | 本番安定・セキュリティ・信頼の土台 |
| **L3** | 中優先 | 運用効率と検索体験の伸びしろ（コスパ重視） |
| **L4** | 低優先 | コーチ向け拡張。**ニーズ・効果を見てから** |
| **L5** | 将来 | 余力・トラフィック増後に検討 |
| **—** | スコープ外 | 意図的にやらない（参考サイトの全機能揃えは非目的） |

**プロダクトの芯（不変）:** 複数チャンネルの練習動画を手軽に検索し、コーチングに活かす。検索ツール＋個人ワークフロー（お気に入り・記録・ボード）。メディア化・全機能コピーは目的ではない。
