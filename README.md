# 少年サッカードリル

少年サッカー向けの練習ドリル動画（YouTube）を、目的・人数・レベルなどで検索できるWebアプリケーションです。

## セットアップ

1. **依存関係のインストール**

   ```bash
   pip install -r requirements.txt
   ```

2. **環境変数の設定**

   `utilities/.env` ファイルを作成し、必要な環境変数を設定してください。

3. **アプリケーションの起動**

   ```bash
   python app.py
   ```
